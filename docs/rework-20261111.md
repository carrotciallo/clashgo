# Phase 1 rework — 2026-11-11 evening

Follow-up to `docs/phase1-mvp-20261111.md`, driven by the first
hands-on trial. The MVP is now the installed build on cachyos
(`~/.local/bin/clashgo`, 14.0 MiB with `-ldflags "-s -w"`).

## What landed

- **TUN capture** (promoted from Phase 2 at the user's direction):
  settings flag, render-time `tun:` injection with the user's own
  block left intact, `dns.listen` ensured, capability grant via
  pkexec, full-restart application with rollback. Live finding baked
  into the defaults: on this machine the mixed/system TUN stacks
  blackhole TCP; **gvisor works** and is the injected default.
- **Capture modes are mutually exclusive.** One segmented control on
  the overview (and one tray toggle) switches between system proxy
  and TUN; TUN parks the GNOME proxy at `none` while keeping the
  previous settings snapshot for exit-time restore.
- **Notice-node filter.** Providers now also carry an
  `exclude-filter` for airport notice entries disguised as real
  nodes (ss entries named like "订阅链接可能已泄露" → 8.8.8.8:12345),
  which had blackholed an url-test group and the first TUN trial.
- **Full-config subscription ingestion (v2).** The IPLC subscription
  answers with a whole 721 KB client config whose nodes are
  proxy-groups over `__dialer_*` proxies; as a provider it
  contributed zero usable nodes. Fetch now detects and splits it
  (66 KB provider file, 30 groups into the registry), and rendering
  inlines the proxies into the main `proxies:` section and merges
  the groups with collision renames （自动选择 → 自动选择·iplc),
  reachability pruning, notice-group drops, and entry groups
  (including one-hop hubs like 国外流量， referenced only by FINAL)
  surfaced in the picker. Key semantic, learned from a live
  `mihomo -t` failure: a group's `proxies:` never resolves against
  provider members — only `use:` does — so inlining is the only
  faithful shape. Verified live: core serves the H/J/S/U groups,
  picker → 国外流量 → U15美国 半费 exits at 148.135.37.20 (US),
  google 200; selections restored afterwards.
- **UI first rework pass:** lavender-blue theme (accent #6675D6),
  card-based pages, close-to-tray (window close hides, quit restores
  the proxy state), tray shows the capture toggle.

## Machine-side cleanups the trial exposed (not code)

- Every hardcoded `127.0.0.1:7890` proxy on cachyos removed, in
  three places: chrome-flags.conf + the Chrome desktop file, and
  Hyprland's `environment.lua` session exports (the last one kept
  Chrome broken after a restart — ERR_PROXY_CONNECTION_FAILED —
  until the compositor env was blanked and Chrome relaunched;
  verified fixed by process-env scan + screenshot). git/pip/pnpm
  point at 7897 since they cannot read GNOME proxy settings; the
  frp/xbcl bypass domains moved to GNOME `ignore-hosts`.
- Detached-launch lesson: GUI instances started from an ssh
  `nohup … &` die with the channel (Wayland display reset in the app
  log at the exact channel-close second, twice). A
  `systemd-run --user` transient unit is detached from the channel
  and is how the trial instance now runs.

## Design round (same evening, after the user's design feedback)

The UI was reworked against the reference clients' actual layouts —
FlClash's card dashboard and chip/card proxies, Shadowrocket's
grouped inset lists — not just its palette:

- **Shared list language:** `sectionHeader` (title + right count),
  `listCard` (one rounded surface per group), `hairline` dividers.
- **Nodes page** is now a Shadowrocket-style grouped list: every
  group is a collapsible section card — header (chevron, name, kind,
  member count, current pick, delay-test button) over
  hairline-separated rows (name, protocol tag, graded delay, check
  on the current pick). 节点选择 starts expanded. Verified live by
  driving the real window: expanded 国外流量， clicked U15美国 半费，
  the core API confirmed the switch; restored afterwards.
- **Rules page** renders rules as structured rows (index, localized
  type tag chip, value, policy in accent/muted/danger) in file
  order, instead of raw strings.
- **Subscriptions page** uses the same grouped list, with a
  整包配置 tag on split subscriptions.
- Capture pill labels were truncating at 84 DIP ("系统代…"); the
  segmented capture control is 108 now.

Drills executed against the real desktop (automation + ground
truth, not screenshots alone): capture switch 系统代理→TUN→系统代理
with GNOME mode/port and the Meta interface checked after each
click; window close → app, core and TUN survive in the tray
(checked twice); tray-click reopen is the one step left to the
user's own first click.

Two defects the drills exposed, both fixed and re-verified live:

- **Stale capture flags.** A capture switch raced a quit (the park
  landed after Disarm had restored the desktop), leaving the state
  file claiming `parked` while GNOME pointed at the dead 7890. On
  the next start Neutralize trusted the flag and no-opped. Arm and
  Neutralize now cross-check the live settings and re-assert
  against the recorded prev when the flag is stale; startCore no
  longer applies a capture switch once a quit is in flight.
  Reproduced deliberately (planted stale state) and verified.
- Instances started inside short-lived ssh channels kept dying with
  a Wayland display reset; the app now runs as a `systemd-run --user`
  transient unit, detached from any channel.

## Structure round (same evening, after the user's second review)

The design round had copied the references' surface but kept the
Clash information model; the user rejected that: the nodes page was
still organized by the core's strategy groups, subscriptions lived
on their own page, configs could not be switched, and the home page
was not a dashboard. The structure now follows the products:

- **Nodes page = subscriptions + nodes, one page.** Each
  subscription is a section whose body is its own node pool
  (provider API for plain subscriptions; surviving fragments for
  split ones — notice-shaped groups no longer render as dead rows).
  One tap makes a node the egress: `useNode` routes directly when
  the node is a picker member, or through the intermediate group
  for split-subscription choices (verified live both ways). Refresh
  / delete / add live on the same page. Strategy groups are demoted
  to a collapsed area at the bottom — demoted, not removed.
- **Profiles （配置）.** Configs are switchable files in
  Shadowrocket's shape: `profiles/<name>.yaml` next to the built-in
  master, listed with modification time and size — orange dot for
  the default, check for the active one, tap a row to switch.
  Switching renders and validates the new file first and reverts
  completely on failure (verified live both directions with a
  planted marker rule). New profiles are seeded from the active
  config. The rules page moved under 配置： the active profile's
  rules and the add form live below the list.
- **Home page as a FlClash-style dashboard:** current-exit card
  with the full selection chain, outbound mode as three large
  tiles, a live-traffic card (rates sampled from the connections
  totals in the poll loop), capture card, subscription summary.
- Navigation shrank from five pages to four: 概览 / 节点 / 配置 /
  设置.

## Not in this round

- Connections page, on-demand repaint (the ~88 MB GUI PSS debt),
  AUR packaging, original icon.

## Dashboard round (same evening, third review)

Side-by-side with the user's FlClash screenshot, the "dashboard"
was still a sparse settings stack. Rebuilt to FlClash's actual
composition: one status band (state, exit identity, uptime,
up/down rates, and the big round core start/stop button — stop in
proxy mode disarms first), one strip holding the outbound-mode
segmented control and the two capture switches, four mini-cards
(LAN IP from the physical interface, active profile, node +
controller latency, app + core memory), and a bottom split of
live connections (plumbing chains filtered out) beside read-only
decision-group status. Strategy groups left the nodes page
entirely, and every add form (subscription, profile, rule) moved
behind a + entry into a modal dialog.

Verified live: FAB stop/start round-trip against process and TUN
state; capture switches both ways against gsettings and traffic;
add-subscription dialog open/cancel; per-page screenshots.

## Import-filtering round (same evening, fourth review)

The dashboard's read-only group panel was still one compromise too
many: in this product there is no group surface at all. The fix
moved to the layer the user pointed at — import. SplitFullConfig
now flattens a full-config payload: every proxy-group is dropped,
leaf groups become plain provider nodes (renamed first member),
and the reachable __dialer plumbing is carried in a sidecar file
that rendering splices into the main proxies: section. The
fragments pipeline (FragmentGroup, mergeFragments, registry
fragments) is deleted, and so is the dashboard's group-status
module and its data path.

Verified live after re-fetching the IPLC subscription: provider
holds exactly 20 nodes, the core's group list is precisely the
master template's four (GLOBAL, 节点选择, 自动选择, 故障转移),
the picker carries zero plumbing members, and egress through the
flattened U15 node returns the same US exit (148.135.37.20) the
subscription produced under FlClash. One casualty of flattening,
as predicted: H01's preferred entry is dead, so that node is down
until the airport rotates it — entry failover was the price.

## Capture-assert round (same evening, after the import-filtering round)

Prompted live: FlClash (still autostarting then) launched during
a session swap and armed GNOME to manual/7890 underneath a
TUN-mode ClashGo. ClashGo now treats capture as ownership that
is asserted, in two halves:

- **Launch grab** — startCore's capture application already
  displaced a foreign arm (Neutralize records a foreign snapshot
  as prev when we did not own the settings; Arm likewise).
  Verified: started against a manual/7890 desktop, ClashGo
  parked it to "none" with TUN up.
- **Watchdog** — `sysproxy.Manager.Reassert`, called from the
  poll loop's slow block: when the state file says we own the
  capture (armed or parked) and the live GNOME settings no
  longer match, ours are written back. The recorded prev is
  never updated by a steal. Verified both modes: an external
  rewrite to manual/7890 was reverted to "none" (TUN) and to
  manual/7897 (proxy) within one watchdog cycle.

Also this evening: FlClash autostart disabled at the user's
order (XDG autostart entry renamed off, Hyprland autostart.lua
line commented); ClashGo itself stays manually launched.
