# Phase 1 MVP Report — 2026-11-11

Branch `feat/phase1-mvp`. Built and verified live on the target CachyOS
desktop against the user's two real subscriptions (267 nodes total).
**The MVP is installed and running as the machine's proxy client**
(`~/.local/bin/clashgo`, GNOME proxy armed at 127.0.0.1:7897);
FlClash remains installed as the fallback.

## What shipped

- **Config engine** (`internal/config`): user-owned `master.yaml`;
  ClashGo manages only marked regions (provider block, group `use:`
  lines). Render → `mihomo -t` (30 s time-boxed) → atomic install →
  hot reload; any failure keeps the previous config serving.
  Snapshots before every master edit, restore from the settings page.
- **Core supervisor** (`internal/core`): mihomo child with PDEATHSIG,
  geodata seeded (case-insensitively) before *any* core invocation,
  API client merging `/proxies` + `/providers/proxies` (this mihomo
  build keeps provider nodes out of the flat map).
- **System proxy** (`internal/sysproxy`): the Phase 0 state machine —
  arm only after `/version` answers, restore on quit, heal on next
  start after an unclean exit.
- **Subscriptions** (`internal/subs`): registry JSON; fetch validates
  the payload shape, writes atomically, keeps the last good file on
  failure. First-run bootstrap fetches missing providers *before*
  validation so validation stays a local operation.
- **UI** (`cmd/clashgo`): tray + five pages （概览/节点/订阅/规则/设置）.
  Text fields use explicit focus (Phase 0 lesson); an e2e-only
  automation link (build tag) allows element-level UI verification.

## The three bugs that mattered (all found live, all fixed)

1. **Validation could hang forever.** `mihomo -t` in a core home
   without geodata blocks on a network download; without provider
   cache files it fetches subscriptions during validation. Fixes:
   seed geodata before any core call, fetch providers at bootstrap,
   time-box validation at 30 s.
2. **Airport info entries captured auto-selection.** Airport lists
   pad with `direct`-type notice entries （剩余/到期） that win every
   url-test delay race and route traffic direct. Fix: rendered
   providers carry `exclude-type: "Direct|Reject"` — subscriptions
   contribute nodes, never pseudo outbounds. (ss-type decoy entries
   remain; url-test's own health checks settle past them.)
3. **Proxy-bound DNS deadlocked everything.** With the main
   nameserver riding the proxy group, resolving the *nodes' own
   server domains* looped back into the proxy. The working reference
   config carried the antidote: `dns.proxy-server-nameserver`
   (domestic DoH via DIRECT). Template now includes it; foreign
   resolution rides the nodes (domestic DoH answers for foreign
   domains are poisoned on this network — measured), CN domains use
   domestic DoH via policy. DNS mode is redir-host, matching the
   reference config.

## Footprint (measured, window open)

- Binary (stripped): 14,215,392 B ≈ 13.6 MiB (< 15 MB target ✓)
- GUI: PSS ≈ 88 MB, RSS ≈ 176 MB. Above the 80 MB aspiration — the
  view currently requests animation frames continuously while the
  window is open (redraw-on-change is the known fix, deferred).
  Tray-resident mode stops polling; its PSS was not separately
  measured this round.
- mihomo core: RSS ≈ 130 MB with 267 nodes loaded (vs FlClash total
  ≈ 313 MB RSS for UI+core).

## Known gaps / Phase 2 candidates

  icon (still the WhiteSur placeholder).

  rollback is quitting ClashGo (proxy restores automatically) and
